# Security

LarchBudget holds your finances, so a security problem matters.

## Reporting a problem

Please do not open a public issue. Report it privately instead: go to
[Report a vulnerability](https://github.com/m-ers/LarchBudget/security/advisories/new)
(the **Security** tab of this repository) and describe what you found and how
to see it.

LarchBudget is maintained by one person in their spare time, so an answer can
take a few days.

## Which versions get fixes

Only the latest release.

## Keeping your own LarchBudget safe

Set a password and use HTTPS before LarchBudget can be reached from outside
your own computer:
[Password and HTTPS](docs/installing.md#password-and-https).
